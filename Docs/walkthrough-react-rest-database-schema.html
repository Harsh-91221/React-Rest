🗄️ Data Schema & API Reference

Data structures used by React-Rest (Namaste Food) — API responses and local state

📡 API Endpoints

1. Restaurant List

GET https://www.swiggy.com/dapi/restaurants/list/v5?lat=28.4808184&lng=77.5177682&is-seo-homepage-enabled=true&page_type=DESKTOP_WEB_LISTING

2. Restaurant Menu

GET https://www.swiggy.com/dapi/menu/pl?page-type=REGULAR_MENU&complete-menu=true&lat=28.4808184&lng=77.5177682&restaurantId={resId}

📦 Restaurant List Response Schema

Nested path: data.cards[4].card.card.gridElements.infoWithStyle.restaurants[]

FieldTypeDescription
idstringUnique restaurant identifier (used in URL routing)
namestringRestaurant name
cloudinaryImageIdstringImage key for CDN URL construction
avgRatingnumberAverage star rating (e.g., 4.5)
cuisinesstring[]Array of cuisine types (e.g., ["North Indian", "Biryani"])
costForTwostringCost for two (e.g., "₹400 for two")
slaStringstringDelivery time estimate (e.g., "28-32 mins")
feeDistancestringDelivery fee distance indicator

📋 Restaurant Menu Response Schema

The menu response contains many cards. The relevant data is at:

data.cards[2].groupedCard.cardGroupMap.REGULAR.cards[]

Menu Card Structure

FieldTypeDescription
card.card.titlestringCategory name (e.g., "Recommended", "Soups")
card.card.itemCardsarrayArray of menu items in this category
card.card["@type"]stringUsed to filter: type.googleapis.com/swiggy.presentation.food.v2.ItemCategory

Menu Item Structure (inside itemCards)

FieldTypeDescription
card.info.idstringUnique item ID
card.info.namestringDish name
card.info.pricenumberPrice in paise (divide by 100 for rupees)
card.info.defaultPricenumberFallback price in paise
card.info.descriptionstringFood description
card.info.imageIdstringImage key for CDN URL
card.info.categorystringCategory label
card.info.isVegbooleanVegetarian indicator
