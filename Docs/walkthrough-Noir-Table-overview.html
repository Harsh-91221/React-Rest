🎯 Project Overview

Noir Table is a Swiggy-inspired food delivery application that lets users browse restaurants, view detailed menus, add items to cart, and place orders. It fetches live restaurant and menu data from the Swiggy public API (proxied through FoodFire).


The project demonstrates core React concepts — component composition, custom hooks, client-side routing, global state management, and API integration — all built with modern React 18 patterns.

🔄 Data Flow

1
User opens app → App.js initializes BrowserRouter and wraps everything in Redux.Provider
2
Body.js mounts → calls useResData() hook → fetches restaurant list from FoodFire API
3
Data flows into RestaurantCard components via props (parent-to-child)
4
User clicks a restaurant → React Router navigates to /restaurants/:resId
5
useRestaurantMenu(resId) fetches full menu data from API and parses nested response
6
User clicks "Add to Cart" → dispatch(addItem(item)) updates Redux store
7
Header re-renders automatically (via useSelector) showing updated cart count badge

🔌 API Endpoints

Restaurant List

GET https://foodfire.onrender.com/api/restaurants?lat=21.17&lng=72.83&page_type=DESKTOP_WEB_LISTING

Restaurant Menu

GET https://foodfire.onrender.com/api/menu?page-type=REGULAR_MENU&complete-menu=true&restaurantId={resId}
Note: All API calls go through the FoodFire proxy server to avoid CORS issues with Swiggy's domain. The coordinates are set to Mumbai, India.

💡 Key Design Decisions

DecisionWhy
Redux Toolkit for cartCart state needs to be shared between RestaurantMenu and Header components. Redux provides a single source of truth without prop drilling.
Custom hooks (useResData, useRestaurantMenu)Encapsulates data-fetching logic, keeping components clean and reusable. Also makes testing easier.
FoodFire proxy instead of direct Swiggy APISwiggy's API blocks cross-origin requests. FoodFire acts as a CORS proxy, enabling browser fetch calls.
React Context for user authSimple user state that only needs to trickle down a few levels. Context is lighter than Redux for this use case.
Shimmer loading skeletonProvides better UX than a spinner — users see the layout structure while content loads.
Dark/Light theme with localStoragePreference persists across page reloads. Uses CSS custom properties on :root for easy theming.
