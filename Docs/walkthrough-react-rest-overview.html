🍽️ Namaste Food (React-Rest)

A food ordering application built with React, Redux, and Firebase

🎯 Project Overview

Namaste Food is a Swiggy-clone food delivery web application that allows users to browse restaurants, view menus, search for food, and manage a shopping cart. The app fetches live data from the Swiggy public API and uses Redux for state management.


It demonstrates core React concepts including component composition, hooks, routing, state management, and API integration.

⚙️ Tech Stack

React 18 UI Framework with Hooks
React Router DOM v6 Client-side routing
Redux Toolkit Global state management
Tailwind CSS Utility-first styling
Parcel 2 Bundle & build tool
Firebase Analytics & hosting
Jest Unit testing framework
Swiggy API Live restaurant data

        │       └── ItemList[]
        └── Cart

🔄 Data Flow

1
User opens app → AppLayout renders
2
Body.js calls useResData() → fetches from Swiggy API
3
Data flows into RestaurantCard components via props
4
User clicks restaurant → Router navigates to /restaurants/:resId
5
useRestaurantMenu() fetches menu data by resId
6
Menu items rendered as collapsible RestaurantCategory sections
7
"Add+" button dispatches addItem() to Redux store → Cart updates

📁 Key Files & Responsibilities

File Responsibility
src/App.js Router setup, AppLayout wrapper with Redux Provider
src/components/Header.js Navigation, online status indicator, cart count, login/logout
src/components/Body.js Search functionality, fetches & displays restaurant list
src/components/RestaurantCard.js Display component for individual restaurant info
src/components/RestaurantMenu.js Fetches menu, renders category accordion
src/components/Cart.js Displays cart items from Redux store, clear button
src/utils/useResData.js Custom hook: fetches restaurants, handles loading
src/utils/useRestuarantMenu.js Custom hook: fetches menu by restaurant ID
src/utils/cartSlice.js Redux slice: addItem, removeItem, clearCart
src/utils/useOnlineStatus.js Custom hook: tracks online/offline via navigator.onLine

🌐 API Endpoints Used

Endpoint Purpose
/dapi/restaurants/list/v5 Fetches list of restaurants with ratings, cuisines, delivery time
/dapi/menu/pl?page-type=...&restaurantId= Fetches restaurant menu with categories and items

Note: Both endpoints are Swiggy's internal APIs. Coordinates are hardcoded to Delhi, India (lat: 28.4808184, lng: 77.5177682).
