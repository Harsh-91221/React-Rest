🗋 Noir Table — Data Schema & API Reference

Data structures, API responses, and Redux state for the React-Rest project

🔌 API Endpoints

1. Restaurant List GET

https://foodfire.onrender.com/api/restaurants?lat=21.1702401&lng=72.8310607&page_type=DESKTOP_WEB_LISTING

2. Restaurant Menu GET

https://foodfire.onrender.com/api/menu?page-type=REGULAR_MENU&complete-menu=true&lat=21.1702401&lng=72.8310607&restaurantId={resId}
Note: The FoodFire proxy strips CORS headers. Coordinates target Mumbai. Swiggy's raw API cannot be called directly from the browser.

🍳 Restaurant List Response Schema

Extracted path: data.cards[4].card.card.gridElements.infoWithStyle.restaurants[]

stringidUnique restaurant identifier (used in route: /restaurants/:resId)
stringnameRestaurant display name
stringcloudinaryImageIdImage key — combined with CDN_URL for full image URL
numberavgRatingAverage star rating (e.g., 4.5)
string[]cuisinesArray of cuisine types, e.g. ["North Indian", "Biryani", "Pizza"]
stringcostForTwoFormatted cost string, e.g. "₹400 for two"
stringsla.slaStringDelivery time estimate, e.g. "28-32 mins"
stringsla.lastMileTravelStringDistance info, e.g. "1.2 km"
stringareaNameLocality / area name
stringtotalRatingsStringTotal ratings count, e.g. "500+ ratings"

🍳 Menu Response Schema

Two data paths exist in the response:

Restaurant Info REQUIRED

data.cards[].card.card["@type"] === "type.googleapis.com/swiggy.presentation.food.v2.Restaurant"

Menu Items REQUIRED

data.cards[].groupedCard.cardGroupMap.REGULAR.cards[]

Each menu card has card["@type"] === "type.googleapis.com/swiggy.presentation.food.v2.ItemCategory" containing an itemCards array.

Menu Item Fields (inside itemCards)

stringidUnique item identifier
stringnameDish name
numberpricePrice in paise (divide by 100 for ₹)
numberdefaultPriceFallback price in paise
stringdescriptionDish description
stringimageIdCDN image key
booleanisVegVegetarian indicator
objectratingRating object with avgRating field
arraybadgesBadges like "chef's special", "spicy" with label text

🖗 Image URL Construction

Restaurant card images:

CDN_URL + cloudinaryImageId

Menu item images:

ITEM_IMG_CDN_URL + imageId
Note: The CDN base URL includes transformation params (width, height, fit, quality). Using the correct suffix for each image size ensures optimal loading performance.
